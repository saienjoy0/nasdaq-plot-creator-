# Project Auditor Skill

## Purpose
Provide whole-project scanning before architecture changes.

## Responsibilities
- Inventory skills, designs, contracts, workflows, tests, and generated artifacts.
- Detect duplicated responsibilities and missing layers.
- Produce architecture gap reports before modifications.

## Position in NASDAQ Cafe
Run before adding or changing production skills.

Flow:
Project Auditor
→ Editorial/Architecture decision
→ Implementation changes
→ Validation

## Output
- Current architecture map
- Dependency map
- Risk list
- Recommended next actions
