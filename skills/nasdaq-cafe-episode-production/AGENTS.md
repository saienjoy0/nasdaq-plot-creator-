# Episode Production Contract

This directory contains deterministic contracts and validators for final 朝のNASDAQカフェ production artifacts.

- Editorial meaning remains governed by project instructions and source-of-truth 02, 01, materialized 03, then 04.
- Validators do not choose the lead, rewrite narration, infer Scene intent, or decide whether remembered claims are true.
- A memory reference may enter the episode package only when it exists in the validated causal dossier and its current revalidation status permits the declared public use.
- `historical_context_only` is comparison context, not current evidence.
- `weakened` and `invalidated` may be used only as counterevidence, historical comparison, or internal context.
- `unresolved` and `not_used` must never be presented publicly as current facts.
- Episodes that use no editorial memory are valid.
