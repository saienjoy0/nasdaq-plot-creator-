# Component Lessons — Phase 2

Store human-approved editorial lessons here only after an exact-SHA Preview approval exists.

Each lesson should state:

```text
Component / visual function
What it helps the viewer understand
Strong use conditions
Weak use conditions
Common misuse
Typical alternatives
Context
What worked
Why
When not to use
```

Do not bind a Component to a fixed Scene number. Do not convert a Lesson into a Hard rule.
