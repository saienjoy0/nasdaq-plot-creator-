# Visual Editorial Intelligence Principles

## 1. First question

For every Beat ask:

> この映像があることで、視聴者は何を「読まなくても」「比較しやすく」「確かめやすく」理解できるようになるか？

If there is no concrete answer, the Visual may have little information gain.

## 2. Information Gain is semantic

Do not score Information Gain numerically. Do not substitute number of components, cuts, screenshots, assets, charts, or motion events for understanding.

Useful gains include:

- compare Expected and Actual on one scale
- see chronology without memorizing narration
- ground an abstraction in a primary source
- separate market-wide and company-specific movement
- expose peer divergence
- make confirmed / inferred / unknown boundaries visible
- show where a causal route stops being supported

## 3. Visual follows Story belief progression

`audienceBeliefBefore` and `audienceBeliefAfter` come from the frozen Story understanding progression. Visual Intelligence can clarify the transition but cannot invent another transition.

## 4. Reality Anchor

A Reality Anchor is useful when it changes the viewer experience from “I was told this” to “I can verify what this is based on.”

Availability alone is insufficient. A screenshot that adds no new ability to verify, compare, or delimit is merely a receipt.

## 5. Visual Turn

A turn exists when information function changes with Story understanding, e.g. hypothesis → source confirmation, one-cause model → peer divergence, abstract route → actual price test.

Layout/color novelty alone is not a turn.

## 6. Visual Economy

Visual continuity can be editorially valuable. Keep the same frame when the viewer benefits from stable comparison coordinates.

Switch only when the next state adds or changes explanatory function.

## 7. Strong late section

Scenes 6–8 should visually perform work that early Scenes could not yet perform: test, compare, bound, falsify, or synthesize.

If replacing late Visuals with generic text leaves understanding unchanged, the visual arc is weak.

## 8. Uncertainty is visible meaning

For `reason_unknown`, the Visual can still be interesting by showing chronology, rejected simple explanations, divergence, and the edge of confirmed knowledge.

Do not draw a clean causal arrow merely because a causal diagram would look better.
