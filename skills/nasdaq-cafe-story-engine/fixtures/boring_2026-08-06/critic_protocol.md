# Independent Critic Protocol — Shadow Round

1. Read only the fixed editorial baseline, Claim Ledger, rules snapshot and completed old package digest.
2. Do not read Author self-scoring or the old 29/30 result as evidence of quality.
3. Identify exact Scene IDs, audience effect and minimum fixes.
4. Preserve all Claim IDs, Evidence IDs, confidence, counterevidence and chronology.
5. Treat unresolved Critical findings as blocking.
6. Re-review the revised package in a separate pass and record PASS only after all Critical findings are fixed.
