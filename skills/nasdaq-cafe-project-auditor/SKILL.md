# NASDAQ Cafe Project Auditor Skill

## Role
Maintain a complete understanding of the project before major changes.

## Responsibilities
- Scan skills, designs, workflows, tests, and production contracts.
- Detect duplicated responsibilities.
- Detect missing pipeline connections.
- Review impact before architectural changes.

## Output
PROJECT_STATE_REPORT:
- current architecture
- changed components
- risks
- recommended next actions

## Rule
Never recommend adding a capability before checking whether it already exists.
