# Topic Threads

一つのthreadは、複数回にまたがる一つの市場論点を扱います。

例：

- `ai-capex-monetization.md`
- `hbm-supply.md`
- `us-chip-export-controls.md`
- `long-yields-vs-megacap-tech.md`

各threadには次を記録します。

1. このthreadが答える問い
2. 最初に扱った日
3. 現在の見方
4. 時系列での重要な更新
5. 強まった証拠と弱める証拠
6. 関係する企業・政策・指標
7. 未解決点
8. 関連するclaim ID

`index.json`へtrigger語、企業、別名を登録しないthreadは、毎朝の自動選択対象になりません。
