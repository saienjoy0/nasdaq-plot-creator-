# Visual Source baseline artifact

`visual_source_baseline.json` is generated by the existing hardened daily-production workflow after:

1. Story Engine materialization and acceptance;
2. final episode package materialization;
3. hardened Final Production;
4. strict Remotion 2.4 validation against the pinned renderer;
5. production consistency validation;
6. immutable preview handoff creation.

The baseline recorder is audit-only. It does not alter narration, market causality, Visual Grammar, Financial Visual decisions, asset selection, or authorization state.

For 2026-08-06, external Critic certification may remain `not_certified` under the explicit `external_critic_optional` production policy. The baseline must never report certified execution unless the Story Engine acceptance actually contains that evidence.
